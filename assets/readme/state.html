Directory structure

All outputs are organised into three subdirectories. There are no loose files at the top level (aside from this README).

DirectoryContents
plots/ Visualisation plots regenerated each round. Contains circle-tree, treemap, taxonomy accumulation, read density, and quality violin images in PNG format.
sequences/ Sequence outputs. Contains Consensus/, where each subdirectory is named after an OTU key (e.g. OTUB_42-COI-sample_1/) and holds the merged consensus FASTA and the supporting reads used in the multiple sequence alignment.
tables/ All tabular report files. Includes cumulative BLAST and read-info reports, OTU definition and frozen-OTU state tables, demultiplexing and on-target reports, treemap data, taxonomy time-series tables, and internal state tracking files (OTU hashes, frozen members, seen read IDs). See below for key file patterns.

Key files in tables/

Files with .gz extension are gzip-compressed; use zcat, gzip -d, or any gzip-aware tool.

File patternContents
*_blast_otu_pretax_rpt.txt Cumulative BLAST OTU pre-taxonomy report. Maps each read to its best BLAST hit and OTU assignment. Columns: read ID, barcode, model, sample, hit ID, taxid, alignment length, percent identity, OTU ID, and full taxonomy (kingdom through species).
*_read_info_rpt.txt.gz Cumulative read info table. One row per read with: read ID, sequence length, mean Q-score, basecalling model, barcode, marker, sample, and on-target status.
*_otu_def_rpt.txt.gz OTU definition report. Cluster membership, OTU sizes per round, taxonomy assignments, and frozen/active status for every OTU cluster.
*_blast_consensus_tax_*.txt Consensus sequence taxonomy assignments (all, representative, and consolidated variants). One row per consensus sequence with BLAST-derived taxonomy at family, genus, and species level.
*_on_target_rpt.txt.gz On-target read tracking. Records which reads passed the marker-specific length and quality filters and were classified as on-target for COI or ITS2.
*_demult_rpt.txt.gz Demultiplexing report. Read-to-sample assignment results including barcode match scores and primer identification.
*_treemap_*_rpt.txt Data tables backing each treemap plot. Contain OTU or consensus read counts by taxonomy, split by marker and taxonomic group.
*_tax_time_rpt.txt Taxonomy accumulation tables (OTU, consensus, frozen OTU, and consolidated variants). One row per round with cumulative species/genus counts.
otu_frozen_*.tsv / otu_seen_*.tsv Internal OTU state files: frozen cluster membership, representative sequences, promotion history, and seen-hash index. Used for pipeline restart and restore.
