Demultiplexing modes — controlled by demultiplex_mode in the run config:
  • auto — use demult.fasta if present, otherwise fall back to primer-only identification.
  • on — always apply full barcode demultiplexing with demult.fasta.
  • primers_only — identify marker (COI/ITS2) via primers.fasta without sample assignment.
  • off — skip demultiplexing; all reads processed as a single pool (no_adapter).
