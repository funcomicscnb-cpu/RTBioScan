Configuration notes
  • POD5 is the current Oxford Nanopore Technologies format for raw electrical signal data.
  • Each round processes one POD5 file (or a configured batch) through basecalling, demultiplexing, and OTU classification.
  • Set delete_input_pod5 = true to permanently delete each POD5 after processing instead of archiving it to done_round_pod5/.
  • Set delete_from_ori_dir = true to also remove the source file from ori_round_pod5/ after processing.
  • In real-time mode (watch = true), the pipeline keeps running and picks up new files as they appear in reads_rt_round_pod5/.
