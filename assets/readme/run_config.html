How to use this file for future runs

Pass -c to Nextflow to load the configuration file, then override only what needs to change for the new run (e.g. new reads path, new run ID):

./RTBioScan.sh \
  -c results/{{RUN_NAME}}_config/{{CONF_FILENAME}} \
  --run_id NEW_RUN_ID \
  --reads "results/pod5/NEW_RUN_ID/reads_rt_round_pod5/*.pod5" \
  -profile <your_profile> -resume

Or directly with Nextflow:

NXF_VER=22.10.8 nextflow run main.nf \
  -c results/{{RUN_NAME}}_config/{{CONF_FILENAME}} \
  -name NEW_RUN_ID \
  --run_id NEW_RUN_ID \
  --reads "results/pod5/NEW_RUN_ID/reads_rt_round_pod5/*.pod5" \
  -profile <your_profile> -resume
Tips
  • Parameters in the params { } block override Nextflow profile defaults. CLI flags override everything.
  • Always update reads, ori_dir, indexes, primer_indexes, and run_id when starting a new run.
  • Set restart_mode = "off" (or remove the line) for a fresh start; use restart_mode = "restore" to resume from a saved state.
  • Database paths (blast_db_specs, blast_filter_db, blast_taxdb) are absolute — verify they are accessible on the target machine.
